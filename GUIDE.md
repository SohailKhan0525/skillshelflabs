# SkillShelf Creator Guide

SkillShelf is for discovering and sharing AI skills that help people build websites.

## Publish a skill

Answer these five questions quickly:

1. What does it do?
2. Who is it for?
3. Which AI tool does it work with?
4. How do I use it?
5. Where are the source and demo?

## Recommended skill page

Include a concise title, plain-English description, creator, AI tool, category, inputs, expected output, source, demo/example, usage instructions, limitations, and prerequisites.

## For new users and vibe coders

Avoid unexplained jargon. Show one concrete example before asking someone to install anything.

## Creator ownership

Only publish skills you created or have permission to redistribute. Keep original attribution and source links when adapting a skill.

## Demo standard

A demo should make the result understandable without requiring the visitor to read the entire source first. Prefer a small, real-looking website or interface over a screenshot-only placeholder.
