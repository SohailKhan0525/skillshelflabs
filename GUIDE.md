# SkillShelf Creator Guide

SkillShelf is for discovering and sharing AI skills that help people build websites.

## Publish a skill

A real submission must answer:

1. What does it do?
2. Who is it for?
3. Which AI tool does it work with?
4. How do I use it?
5. Where are the source/code and creator-owned demo?

## Required listing information

Include a concise title, plain-English description, creator, AI tool, category, source/code URL, creator-provided demo URL, usage instructions, limitations, and prerequisites.

Do not submit placeholder content, fabricated examples, fake metrics, or a demo created by SkillShelf on your behalf.

## For new users and vibe coders

Avoid unexplained jargon. Explain the real workflow and show the actual creator-provided demo.

## Creator ownership

Only publish skills you created or have permission to redistribute. Keep original attribution and source links when adapting a skill.

## Demo standard

The demo belongs to the creator. SkillShelf does not generate or host a fictional demo for a listing. Provide a real URL that demonstrates the actual skill or its real output.
