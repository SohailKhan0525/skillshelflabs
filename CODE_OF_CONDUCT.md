# Code of Conduct

SkillShelf is intended to be a welcoming, constructive community for people building and sharing AI skills.

## Expected behavior

- Be respectful and specific.
- Give feedback about the work, not the person.
- Credit original creators.
- Do not harass, threaten, or publish private information.
- Keep discussions focused on improving the project.

Project maintainers may remove contributions or participation that violates these expectations.
